# 🚓 KirilPlay: Bumper Catcher 

![Python](https://img.shields.io/badge/python-3670A0?style=for-the-badge&logo=python&logoColor=ffdd54)
![Pygame](https://img.shields.io/badge/pygame-informational?style=for-the-badge&logo=python)

Моя первая полноценная 2D-игра, написанная на Python с использованием библиотеки **Pygame**. 
Это динамичная аркада на выживание и реакцию: вам нужно собирать предметы на экране, пока на вас буквально падают проблемы!

## 🎮 Геймплей и механики
- **Сбор бамперов:** Перемещайтесь по экрану и собирайте появляющиеся бамперы, чтобы зарабатывать очки.
- **Падающая угроза:** Сверху непрерывно падают полицейские. Ваша главная задача — уворачиваться от них любой ценой!
- **Динамика:** Требуется хорошая реакция, чтобы успевать забирать бамперы из-под носа у падающей полиции.
- **Звуковое сопровождение:** Веселые звуковые эффекты при сборе предметов и взаимодействии с полицией.

## 🚀 Как запустить игру

У вас есть два пути, чтобы поиграть:

### Вариант 1: Быстрый запуск (Только для Windows)
Вам даже не нужно устанавливать Python!
1. Скачайте репозиторий к себе на компьютер (зеленая кнопка `Code -> Download ZIP`).
2. Распакуйте архив в удобное место.
3. Запустите готовый файл `KirilPlay.exe`.
4. Наслаждайтесь игрой!

### Вариант 2: Запуск из исходного кода
Если вы хотите посмотреть код или запустить игру на другой ОС:
1. Убедитесь, что у вас установлен [Python 3.x](https://www.python.org/).
2. Установите библиотеку Pygame через терминал/командную строку:
   `pip install pygame`
3. Запустите главный файл игры:
   `python main.py` (или скрипт с логикой игры)
